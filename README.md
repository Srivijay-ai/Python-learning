# NUMBER GUESSUNG GAME:-

About the Project:-

This game is my first  project in Python! It's a simple game where the computer randomly picks a number, and the player has to guess it.

TECHNOLOGIES USED:-
Python

HOW TO PLAY:-
Run the Python program
Enter your guessed number
Read the hints provided by the game
Continue playing until you guess the correct number! 

HOW TO RUN:-
Install Python in your PC 
Download the file: number_guessing_game.py
Open a terminal in the folder where you saved the file
Run this command:
python number_guessing_game.py

RULE:-
User should enter the number between 1-100.If it's entered wrong, the program should say, "Invalid Number"
If the user guessed number > secret number, then program should say, "You number is greater than the secret number"
If the user guessed number < secret number, then program should say, "You number is lesser than the secret number"
