# NUMBER GUESSUNG GAME:-

About the Project:-

This game is my first  project in Python! It's a simple game where the computer randomly picks a number, and the player has to guess it.

TECHNOLOGIES USED:-  
Python

HOW TO PLAY:-  
1)Run the Python program  
2)Enter your guessed number   
3)Read the hints provided by the game  
4)Continue playing until you guess the correct number!  

HOW TO RUN:-  
1)Install Python in your PC   
2)Download the file:  
number_guessing_game.py  
3)Open a terminal in the folder where you saved the file  
4)Run this command:  
python number_guessing_game.py  

RULE:-  
1)User should enter the number between 1-100.If it's entered wrong, the program should say, "Invalid Number"  
2)If the user guessed number > secret number, then program should say, "You number is greater than the secret number"  
3)If the user guessed number < secret number, then program should say, "You number is lesser than the secret number"
